## 项目看点

- **真实三模态输入**：读取同场景RGB、红外、深度图；共享连续浮点预处理与有效深度几何处理，训练时保持三模态同步增强。
- **YOLO / D-FINE独立入口**：训练、预测各自组织，共用基础预处理和输出工具，方便研究不同检测框架。
- **可追溯的融合探索**：保留早期融合、独立辅助分支、局部质量门控和细节注入的实现与实验记录。
- **完整提交链路**：预测图片、带置信度标签和团队提交材料由固定流程导出，已有结果不覆盖。
- **记录收益，也记录退步**：保留不同划分、训练日程、裁剪与阈值实验的结果，明确哪些结论有证据、哪些还待验证。

适合查阅多模态目标检测的工程组织、训练与推理一致性处理，以及有限数据下的实验复盘。若你复用了实现或发现问题，欢迎通过[Issues](https://github.com/crazyzzpdt/AICOMP/issues)交流，并注明框架、数据划分和配置。

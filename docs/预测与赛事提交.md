更新：2026-09-23。当前为复赛；预测框算法不因材料打包改变。本轮没有运行预测、测试或训练。

## 运行与模型选择

用户当前默认：YOLO v5_full/weights/best.pt，1280，FP32，单标签，conf=0.001、iou=0.7、max_det=100；数据源“datasets/test”，输出“历史产出/复赛predict_v5”。D-FINE单独使用predict2.py。默认权重不是最新v20，也不自动切到v4/v14。

```powershell
uv run python predict1.py
```

输出已存在时必须使用新目录，不清空旧结果。例如显式选择历史v4：

```powershell
uv run python predict.py --weights runs/detect/AIC_RGBIRDepth_yolo26l_1280_v4_clean_lr1e4/weights/best.pt --source "数据集/复赛测试集" --imgsz 1280 --height 1280 --output predict_v4_round2_new
```

旧YOLO走v4逐张原生矩形/NMS；batch=4可用于读取调度，不代表该后端一次前向4张。带项目元数据的融合模型自动走训练对应方形/矩形批量路径；D-FINE保持其训练尺寸和原生查询排序，不能照搬YOLO NMS。v20 RGB诊断权重禁止提交。

visual_conf仅影响画框，PNG压缩仅影响保存；都不改变TXT候选。分辨率须按所选权重契约，不是原图1920×1080就应强行以1920预测。没有“首轮AP95≥0.4必胜”或本地AP到赛事分数的可靠换算。


缺队伍信息时使用“复赛材料待补队伍信息”占位，不能直接当正式命名。排行榜ZIP不加入权重、图片、报告或代码；审阅材料通过赛事指定网盘/系统渠道另交，不自动上传。

每个TXT为class_id、归一化中心x/y、宽/高、confidence；类别0–11，ball=7。按原图尺寸恢复坐标，每图最多100框；空结果仍有同名空TXT。全量配对、格式及ZIP完整性校验失败不生成正式结果包，保留现场，禁止手工改测试预测。

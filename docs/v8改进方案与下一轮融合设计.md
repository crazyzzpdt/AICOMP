# v8改进方案与下一轮融合设计

后续实施更新：用户已批准本方案，并将输入要求改为1920×1080。当前main.py和predict.py已切换为独立v9门控融合实验，网络画布1920×1088，默认训练batch=2、预测batch=4。下文1280和“尚未实现”保留为当时的候选设计，不再是当前入口；最新实现与未测试边界见 [v9融合训练实施](v9融合训练实施.md)。这不代表完成训练或已有提分证据。

日期：2026-09-18。本文回应“综合历次训练、老师建议与QQ群经验制定最好方案”。这是当前证据下优先推荐的候选设计，不是已验证的最优模型。本轮只制定方案，未修改训练/预测实现，未执行测试、训练或额外评估。

原v8为已完成的D-FINE-L，线上53.5740，保持其名称和结果不变。下一轮如实施本文，使用独立实验名 `AIC_RGBIRDepth_yolo26l_1280_v9_fusion`，本文称“v8改进方案”不代表覆盖原v8。

## 1. 明确选择

优先采用 **YOLO26l官方RGB预训练主干 + 红外/深度轻量分支 + 多尺度门控残差融合 + 同一检测器**。1280输入，沿用当前清洗版1709/291划分，用固定短周期、明确收尾和一致的验证/提交路径完成下一轮正式训练。

选择理由是本项目v4的55.6000仍为最高已知线上结果，D-FINE v6/v7/v8分别为55.1490/52.4010/53.5740。它支持把有限预算优先投入YOLO路线，不证明YOLO在相同数据和配置下必然胜出。特征融合属于尚未验证的新变量；多项改动同时实施后，不能把涨跌归因给某一个组件。

## 2. 历史经验转为设计决策

| 证据 | 本轮决定 |
|---|---|
| v4清洗版线上最好；v6/v7也已使用清洗标签 | 保留既有清洗和数据审计，不重复下载或把清洗当成后续缺失项 |
| v5球类AP50由0改善至约42%，但线上跌至51.0830 | 保留正确类别迁移；取消第一轮的大范围弱类重复、定向裁剪和模态缺失组合 |
| v7垃圾桶定位改善，但船、球等回退，1536线上未受益 | 主分辨率1280，增强温和，不同时增加大图、P2头、裁剪和重采样 |
| v8第27轮早停，第41轮收尾没有执行 | 收尾提前到第81轮；新120轮训练的早停须允许至少20轮收尾 |
| 新验证集增加JPG、无人机、三轮车和球覆盖 | 固定1709/291，避免每一轮换验证集再横比AP |
| 旧验证无人机仅3框、三轮车仅2框 | 不以旧验证接近满分当作已解决泛化 |
| 红外有模糊/黑边，部分深度图零区域多 | 为模态设计独立特征提取和可学习门控；同名同尺寸不等于像素完全配准 |
| v8垃圾桶AP50提高但AP95回退 | 以总体AP95选主权重，同时记录逐类AP95，不能只追AP50或训练分类损失 |

## 3. 老师建议与群聊的取舍

- **采纳：定向标注审阅。** 老师建议的约200张人工复核仍有价值；以前看过部分审阅图，不代表已对2000张完成逐框确认。重点看漏标、错类、截断框、边缘框、跨模态视野差异，而非按模型不识别就删标注。
- **采纳：分层微调与温和收尾。** 用低一些的RGB骨干学习率保护预训练表示，用较高学习率学习新增分支；预热5轮，不照搬D-FINE的30轮预热，也不冻结整个骨干30轮。
- **延后：难例重采样。** 模型漏检可能来自标签问题、极小目标或模态质量，不能自动当成应该重复训练的好样本。第一轮维持每张训练原图一次主采样。若以后仍需难例挖掘，先审阅官方训练图，再采用有上限、按场景去重的采样；用户未授权额外模型评估时，不另跑全训练集预测。
- **保留为假设：RGB+IR可能优于直接拼接深度。** 聊天没有公开配方，不能视为本机结论。深度仍真实参与模型，贡献由训练学得；不采用固定清零或极小固定权重伪装三模态。
- **不采用：以五个相同架构权重做WBF投票。** 截图许可互相矛盾，后续具体问答指出违规；最终使用一份模型权重、一个检测输出。模型内部特征融合不等于五份检测结果加权。
- **暂不开：TTA、切片重检测和WBF。** 老师预计的加分不是本项目实测，而且截图未明确确认单模型结果融合的许可；暂不把它们纳入正式默认配方。
- **修正：conf在0.2–0.4扫描不是AP提分定律。** 高阈值会裁掉低分真阳性，F1最佳阈值也不等于AP最佳阈值。保持低候选阈值计算AP，显示阈值与提交阈值分开。

仅使用官方2000组。图像来自 `数据集/训练集/AIC2026_Train_2000/{visible,infrared,depth}`，标签来自 `数据集/训练集/new_labels_2000`，训练读取 `datasets/data.yaml`。

继续保留57个标签文件的既有修订，来源审计为 `runs/dataset_cleaning/official_refresh_20260918_214843/manifest.json`。此次重新下载比对6000张图像与新版标签变化0，不能声称获得了新的训练信息。

建议新增的人工审阅清单只取train：含ball约40张、garbage can约40张、light约30张、boat约30张、低清JPG约20张、普通类/背景约40张，按不同场景优先并去重，类别不足时用其他未审阅样本补齐；这是待做清单，不是已完成200张。val不按模型误差反复修订来迎合分数；确有客观标签错误时需单独审计并注明指标可比性变化。

只修复可确认的标签错误，记录文件名、原行、新行、证据与原因。暂不能确认的模糊/遮挡目标保留官方标注；不直接删除“难图”，不人为补出不可见目标。IR偏移是数据/传感器问题时，也不能只移动RGB标签来适应它。

此前空间清理已删除两次before备份中的images目录及废弃code_cleanup备份；审计和历史标签仍在。恢复旧划分须按清单从保留的官方图像重建，不能再把before当作完整三模态目录直接搬回。此次方案不继续删除文件。

## 5. 融合结构

外部保持RGB3+IR1+Depth1五通道输入。进入模型后拆分：RGB走完整预训练YOLO26l主干，IR与Depth分别走轻量卷积分支。在主干P3/P4/P5输出处，把辅助分支投影到对应通道，门控融合后送入同一个YOLO颈部及检测头。

每个尺度的形式为：`F = F_rgb + sigmoid(G_ir) * P_ir(F_ir) + sigmoid(G_depth) * P_depth(F_depth)`。门控依据RGB和对应辅助特征联合计算，随空间和图像内容变化。首版使用普通轻量卷积，不引入大型跨模态Transformer或可变形对齐模块。

- RGB主干保持原始三通道卷积及可迁移权重；不把已有五通道项目检查点直接装入新结构。
- RGB及颈部从本地 `orgin_models/yolo26l.pt` 迁移；分类层仅按明确的类别语义迁移，保留sports ball→ball、比赛ID=7核对。不能把COCO某一个动物类直接当作整个animal类。
- 两个辅助编码器及门控随机初始化，辅助分支采用适合小批次的归一化；投影输出初始幅度较小但非零，门控可学习，避免门控和投影同时全零而阻断学习。
- 三模态和标注共用几何变换；HSV仅作用于RGB。深度PNG保留现有已审计缩放规则，JPG仅当作灰度辅助图，不假装是物理毫米深度。第一轮不额外改变深度量化流程。
- 已知由letterbox产生的填充可以显式屏蔽；原始图里的零值/黑色仅作为质量线索，未经确认不全部硬判无效，也不把真实夜间暗区域清掉。
- 空间门控有助于学习模态贡献，但不能保证修正严重配准偏差。只复用正式训练已有前向，记录IR/Depth门控分布及分支梯度概况；它们用于发现失活，不等于证明分支带来AP增益。
- 最终仍是一个检测器。YOLO26训练原生有两个分配分支，正式预测只用一对多分支，不融合两头的结果。

## 6. 第一轮正式训练参数

以下为待实现候选，不是当前main.py已经支持的参数集合，不是通过搜索得到的最优参数。

| 项目 | 选择与依据 |
|---|---|
| 初始化 | 官方YOLO26l RGB预训练；新融合分支随机初始化；resume=None |
| 数据 | 当前1709/291固定划分、同一清洗审计 |
| 分辨率 | 1280，保留小目标像素并控制新分支开销 |
| batch / 有效batch | 物理4、有效16；新结构若显存不足改物理2并保持有效16，由用户管理资源 |
| 精度 / 加载 | 训练BF16；workers=4、预取1批、pin_memory=False、cache=False，避免重建大量磁盘缓存 |
| 训练长度 | 最多120轮，余弦周期按120轮设置，不再用5000轮控制其他日程 |
| 优化器 | AdamW，关闭auto自动换优化器 |
| 学习率 | RGB主干2e-5；颈部及检测头1e-4；新IR/Depth及门控2e-4 |
| 预热 / 末端倍率 | 5轮；lrf=0.01，预热与衰减保持各组倍率 |
| 权重衰减 | 5e-4，沿用v4量级；偏置和归一化参数不衰减，记录实际缩放后的值 |
| Mosaic | 前80轮0.25，第81轮起0；三模态使用同一拼接位置 |
| 几何增强 | scale=0.2、translate=0.05、fliplr=0.5；旋转、透视、上下翻转关闭 |
| RGB增强 | hsv_h=0.01、hsv_s=0.15、hsv_v=0.15，仅RGB |
| 收尾增强 | 第81轮起Mosaic/scale/translate置0，保留水平翻转与温和RGB增强 |
| 采样与额外增强 | 普通采样；不启用定向裁剪、低清模拟、模态缺失、MixUp、CopyPaste |
| 类别权重 | cls_pw=0；正确类别迁移优先，不与重采样叠加 |
| 框和类别损失 | box=7.5、cls=0.5，保留本机YOLO26实际定位损失；不把D-FINE损失数值移植进来 |
| 早停 | 第81轮重置耐心，第100轮结束起才允许早停；patience=20、min_delta=0.0002，任何真实AP95新高仍保存best |
| 保存 | best.pt按AP95；best_map50.pt单独留存；last.pt可恢复；每20轮完整检查点 |

物理batch、归一化行为与新架构峰值显存尚未实测，不能把历史五通道模型的11.7GiB当作本结构实测值。120轮、分层学习率、收尾门槛都是正式训练起点，不保证已最优。

## 7. 必须处理的YOLO26检测头日程

本机 `.venv/Lib/site-packages/ultralytics/utils/loss.py` 中E2ELoss的一对多权重从0.8向0.1衰减，分母依赖总epochs；一对一为剩余权重。v4/v5设5000轮，使前100–200轮仍以一对多损失为主。直接改成120轮会在同等轮数下改变这一平衡，而项目预测显式 `nms=True` 使用一对多分支。

新方案明确选择**整个120轮固定一对多/一对一损失比例0.8/0.2**，让最终提交分支持续获得监督；这是自定义候选设计，接近旧配方早中期的比例，并非已证明修复了线上低分。保持原生分配算法，YOLO双头权重单独记录，不再借5000总轮数间接控制。

当前本机E2ELoss返回的分项日志来自一对一分支，因此旧训练日志的分类损失下降不自动证明用于NMS提交的一对多分支改善。实施时分别记录两头损失，复用同次训练前向，不增加评估轮次。

## 8. 验证与提交一致性

- 正式训练轮末验证和最终预测使用同一单标签NMS函数、一对多输出、conf=0.001、iou=0.7、max_det=100、agnostic_nms=False；候选按置信度截断，不设置类别保留名额。
- 验证和预测共用原尺寸读图、五通道顺序、归一化、1280等比矩形填充与坐标还原；padding和批次形状策略也一致。不能只改预测尺寸、直拉伸或深度归一化来适配旧权重。
- 首个提交基线使用FP32；visual_conf=0.25只影响展示。保持单权重、单尺度、无TTA/WBF和弱类重检测，不手工抬高某类分数。
- 每轮既有验证产生AP50/AP95、12类指标、PNG/JPG域指标和样本数；复用输出，不新增模型前向。JPG目前只有一个新增验证场景，分域指标不作为可靠的整体替代。
- 主权重按统一流程的mAP50-95择优，AP50最佳只是备用候选。若分数相近，结合连续轮次稳定性和弱类定位趋势选择，不按某个稀有类一次满分决定模型。
- 预测读取检查点中的结构版本和预处理配方，显式导入自定义融合模块。现有predict.py支持旧YOLO和D-FINE，不代表只换成未来新权重就自动兼容新模块。

## 9. 实施顺序与范围

1. 如进行新的人工标签审阅，先完成记录再固定该轮数据签名；已有正确清洗数据可直接作为候选起点，不以重复清洗为开训前置条件。
2. 实现融合模块、迁移映射与独立参数组，并显式处理双头权重日程。复用现有五通道数据读取，不继承v5全部增强和采样副作用。
3. 同时接入训练验证和预测加载，保存结构/预处理版本、数据签名和配置；不覆盖原v8运行或用户当前预测默认权重。
4. 用户启动一次正式训练；利用本来就有的轮末验证选权重。根据用户约束，不自动启动pytest、冒烟测试、独立复评、全训练集预测或参数搜索。
5. 正式训练结束后优先生成AP95最佳的单模型提交包，记录权重和ZIP指纹、预测配置及真实线上分数。

目前main.py仍为已完成的D-FINE v8配方，直接运行不会得到本文新融合结构。本文交付为方案文档，新模型需完成第2–3步实现并重新训练后才可使用。

达到60仍需线上结果确认：当前55.6000到60差4.4分，不能把老师或群聊中各项“预计加分”相加当作保证。方案的核心是保留已有效的预训练与提交路径、改善模态融合、控制训练日程，而不是同时堆满所有建议。

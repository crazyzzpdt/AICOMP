# v10复盘与v11筛选方案

更新：2026-09-20。结论来自已有`results.csv`、逐类指标、训练日志、预测元数据和用户线上分数；没有重新训练、推理、复评或执行测试。

## 结论

v10不是因为只训练49轮而欠拟合。其最佳mAP50-95出现在第19轮（0.33592），此后训练损失继续下降，验证损失总体恶化，连续30轮没有刷新AP95并按配置早停。继续沿同一轨迹训练更可能加深过拟合，不能以延长轮数作为主方案。线上50.9240也低于v4的55.6000。

“首轮mAP50-95必须达到0.4”不适合作为停止条件：v4首轮为0.29976，最终验证峰值0.40370且线上55.6000；若使用0.4首轮门槛，当前最强历史模型也会在第一轮被误杀。首轮可用于发现明显的通道、标签或迁移错误，但不能预测最终上限。

## v10暴露的问题

v10第19轮相对v9最佳的AP95变化并非整体小幅波动：seat约下降8.05个百分点、ball下降16.12个百分点，boat、animal、car和tricycle也回退；person、bicycle、light和uav有所上升。尤其ball首轮AP95为0.35996，v10最佳总体轮仅0.03541，说明类别头和语义迁移能够识别ball，但后续优化将其破坏；这不支持“融合代码从未学到ball”的解释。

v10相对v9同时改变了架构、学习率、增强和`cls_pw`，无法从一次运行证明唯一因果。已有历史提供一个值得优先隔离的方向：v4/v10启用`cls_pw=0.25`时ball表现差，而v5/v9关闭该项时ball明显更可用。类别频率权重同时影响对应类别的正负分类项，并不是只增强正样本。因此v11只关闭该项，其余关键条件保持不变，避免继续一次改多个变量。

## v11配方与阶段筛选

v11继续使用官方YOLO26l、五通道首层融合、清洗版1709/291、1920×1080内容/1920×1088张量、AdamW全模型1e-4、batch4/nbs16、120轮余弦，以及v10相同的前40轮增强和后续完整画面阶段。唯一训练变量是`cls_pw: 0.25 → 0.0`。

为节省明显弱配方的时间，训练器在指定轮次检查“从第1轮至当前的历史最佳mAP50-95”，不是检查单轮值：

- 第10轮历史最佳低于0.31：停止；该值低于v4第5轮，也容许短期波动。
- 第20轮历史最佳低于0.34：停止；v4在此之前已明显越过，v10则无法达到。
- 通过两关后继续由`patience=30`和AP95择优控制；门槛通过不代表一定超过v4或线上60分。

停止时仍保留当轮结果与检查点，用于复盘；未通过的候选不建议提交比赛。若v11通过第20轮但ball再次从早期高点大幅塌陷，下一步应检查逐类分类梯度或采用受限的train-only类别采样，而不是恢复`cls_pw`、盲目加轮数或改预测阈值掩盖训练问题。

## 运行

```powershell
uv run python main.py
uv run python predict.py --weights runs/detect/AIC_RGBIRDepth_yolo26l_1920x1080_v11_no_class_weight/weights/best.pt --imgsz 1920 --height 1080 --output predict_v11
```

预测必须使用实际生成目录。赛事提交仍为单模型、单轨迹best权重，不使用投票、WBF或测试集调参。

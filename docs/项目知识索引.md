## 2026-09-23 高分项目排查结论

- 对公开的 CityViMD-Net 方案核对后，最值得借鉴的是稳定的五通道早期融合、红外单通道、16位深度按 20000 毫米归一化、三模态同步等比例缩放与单标签 NMS；不能仅凭其公开 README 断言 59.877 分可完全复现。
- 排查发现旧版 `train1.py` 的 `architecture="rgb_v20"` 实际只训练 RGB 三通道，不能作为赛事三模态候选；现已改为 `architecture="early_v10"`，并将运行名改为 `AIC_RGBIRDepth_yolo26l_1280_early_fusion_v21`。
- `predict1.py` 默认权重已恢复为历史五通道基线 `v4_clean_lr1e4/weights/best.pt`，保持 1280、v4 几何和单标签 NMS。此次仅修正入口契约，尚未训练或推理，不能宣称 v21 已提升。

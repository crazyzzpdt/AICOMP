# v12复盘与v13训练方案

更新：2026-09-20。只读取v12正式训练产物、历史v4结果和源码，没有运行测试、额外评估、训练或推理。

## 根因

v12第10轮被阶段筛选停止，但不是因为曲线已经恶化。其AP95从第1轮0.26555逐步达到第7轮0.33056，并在第10轮刷新到0.33257；同期mAP50达到0.55075。ball第10轮AP50=0.58091、AP95=0.45121，也没有出现v10式塌陷。

停止门槛0.34来自v4旧256张验证集，而v12使用当前291张验证集。当前验证集包含从旧训练划分移入的场景，v4权重见过其中一部分；两条曲线不能用于绝对阈值标定。v12距离门槛仅0.00743，且当轮仍创新高，因此阶段筛选造成了假阴性。

用户补充的v11线上成绩为44.4710，已纳入历史记录。该结果进一步说明不能用本地单轮指标直接换算赛事分数，但不改变v12门槛缺乏同口径依据的事实。

## v13唯一改动

v13保持v12的模型、官方初始化、清洗数据、1280原生方形几何、batch4/nbs16、AdamW 1e-4、200轮余弦、前100轮Mosaic0.5、后100轮关闭Mosaic、HSV全0、`cls_pw=0`、固定双头和预测路径不变。

唯一改动是删除第10/20轮硬门槛，让AP95最佳权重和`patience=100`决定停止。这样才能检验v12上升轨迹能否在关闭Mosaic前后继续改善。此次不叠加弱类采样、RGB单模态或新结构。

## 运行

```powershell
uv run python main.py
uv run python predict.py --weights runs/detect/AIC_RGBIRDepth_yolo26l_1280_v13_native_full/weights/best.pt --imgsz 1280 --height 1280 --output predict_v13
```

v13是否超过v4仍须由完整训练和正式赛事提交确认，不预先承诺60分。

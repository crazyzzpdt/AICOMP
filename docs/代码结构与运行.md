# 代码结构与运行

2026-09-19：按用户要求减少根目录Python文件，移除中转层；本轮不更换模型，不调整参数，不改数据或权重。

## 日常只用两个入口

```text
main.py                 训练参数与启动
predict.py              预测参数、推理、结果保存、提交ZIP打包
aic/
  __init__.py           包声明，不启动任务
  data.py               三模态读图、类别定义、文件指纹
  model.py              模型结构、共用几何变换与NMS
  training.py           当前训练器、数据集、正式轮末验证
tools/
  __init__.py           工具包声明
  prepare_dataset.py    有记录的数据审计与清洗
```

训练运行 `uv run python main.py`；预测及打包运行 `uv run python predict.py`。
当前main.py存在宽高索引未同步的已知阻塞：IMAGE_HW为(1920,1080)，image_width为1920，但imgsz仍取第二项1080；需先将imgsz对应到第一项1920。此次文档提交不修改用户参数，不宣称当前入口可直接开训。完整依据见[v9融合训练实施](v9融合训练实施.md)。
预测参数仍在文件底部的 `predict(PredictionConfig(...))` 分节配置，权重/输入/输出常量在文件顶部；命令行覆盖方式不变。
数据准备仅在明确需要时运行 `uv run python -m tools.prepare_dataset`，它不会随训练或预测自动执行。

## 合并与删除

- 三模态预测.py、FusionPredictor及DFinePredictor合并至predict.py。D-FINE的模型构建、旧版预处理和查询排序一并迁入，保留旧权重预测，不保留旧训练循环。
- 三模态融合.py中的可序列化模型及共用几何/NMS归入aic/model.py。
- 三模态训练.py中的读图归入aic/data.py；数据集及仍需要的加载器/学习率逻辑归入aic/training.py。
- 融合训练.py归入aic/training.py；FusionDetectionTrainer直接继承框架DetectionTrainer，不再经过旧MultimodalDetectionTrainer中转。旧ScheduledMultimodalDetectionTrainer等无当前用途的训练实现移除。
- 准备三模态数据集.py移至tools/prepare_dataset.py，类别和文件指纹抽出为共享数据组件，预测不再依赖清洗脚本。
- 旧v5训练优化.py已删除。以上旧文件均可从Git提交08a4180恢复，没有删除历史数据或权重。

保留的模型、数据集与训练器子类是框架扩展点，不是额外运行入口。预测不导入训练器或清洗工具；训练和预测共用同一份读图及几何函数，避免两份实现逐渐不一致。

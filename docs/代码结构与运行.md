# 代码结构与运行

更新：2026-09-23。根目录只有两个业务入口；本轮文档和提交材料调整不改变v20训练配方。

## 模块职责

| 文件 | 职责 |
|---|---|
| main.py | 原生YOLO分节配置；当前v20 RGB诊断入口 |
| predict.py | 唯一预测入口；多模态加载调度、后处理、图片/TXT/ZIP及复赛材料导出 |
| aic/model.py | 可序列化模型、历史权重兼容、共用几何与NMS |
| aic/data.py | 三模态读取、类别、数值映射与指纹 |
| aic/training.py | 数据集、训练器、正式轮末验证、审计与权重保存 |
| tools/prepare_dataset.py | 有记录的数据准备与清洗；不在日常训练前反复运行 |

历史中文模块已迁移，不应重新创建中转入口。历史源码、依赖和文件名见[旧运行合订本](归档/05_旧运行与环境记录.md)。

## 当前训练

在项目根目录执行：

```powershell
uv run python main.py
```

这会启动v20诊断，不是已验证提分的新三模态候选：1280、batch4/nbs16、val_batch1，200轮学习率日程、20轮预算。详细配置及对照判断见[v20计划](v19复盘与v20模态诊断.md)。官方三模态数据仍参与配对与增强，但网络仅接收RGB，禁止用此权重生成赛事提交包。

现有datasets无需重建。正式训练中的val=True用于选权重和早停，不因默认禁测而关闭。不自动执行额外测试、语法执行检查、评估、训练或预测；本次未运行这些任务。

恢复仅适用于同源码、同配方、同审计的中断检查点；已完成/预算结束/早停权重不能作为resume继续。更改源码后，旧中断运行应使用其code快照，不绕过指纹校验。

## 预测与材料

当前用户选择v5 best.pt，数据源为“数据集/复赛测试集”，输出为“复赛predict_v5”。更换候选必须显式指定权重；不自动选择最近训练目录，不默认提交v20。完整命令见[预测与赛事提交](预测与赛事提交.md)。

预测后打包采用所选权重运行的训练快照，而不是当前main.py；若历史快照缺失则记录待补，不冒充训练复现完整。提供实际使用的Ultralytics源码副本与依赖版本，因为仅记录pip版本不足以复现项目修改。

## 数据与Git边界

datasets为训练工作数据；“数据集”为官方来源；runs为本地产物。仅datasets/data.yaml入库，模型、赛事图像、标签、预测包、训练产物和原始PDF均不上传GitHub。自定义预测目录须加入忽略规则。

本轮保留未跟踪tests/及tools/validate_local.py，不执行、不提交、不删除它们。旧测试记录只代表当时结果，不能当作本轮验证。

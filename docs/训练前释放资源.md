## 0. 给 AI 的使用说明

把本文件交给 AI 并说明"训练前释放资源"，按下面顺序执行：

1. 读第 1、2 节，确认收益预期与**保留清单**（杀错进程会导致桌面或本次会话中断）；
2. 跑第 4 节的安全检查（提权状态、系统代理、运行中的虚拟机）；
3. 执行第 3 节的 A（普通权限进程）与 B（提权服务）；D/E/F 段属于**持久性配置改动**（暂停更新、禁用自启、禁用计划任务），必须先取得用户同意再执行；
4. 用第 5 节验证，并报告清理前后的可用内存与 GPU 占用；
5. 若扫描出的进程/服务与本文件清单不同（换过软件），先列出来给用户确认再动手。

## 3. 清理清单

### A. 普通权限：用户级进程

```powershell
$targets = 'cc-switch','msedgewebview2','SearchHost','Widgets','WidgetService',
  'kernelUpdate','YunDetectService','OfficeClickToRun','AsusUpdateCheck',
  'WinRAR','Rar','UnRAR',
  'CrossDeviceResume','AppActions','DataExchangeHost','UserOOBEBroker',
  'LockApp','PrintDialog','SystemSettings','ApplicationFrameHost',
  'StartMenuExperienceHost','TextInputHost','ShellExperienceHost','ShellHost',
  'TabTip','RuntimeBroker','dllhost','smartscreen'
$freed = 0
foreach ($name in $targets) {
    foreach ($p in @(Get-Process -Name $name -ErrorAction SilentlyContinue)) {
        $mb = [math]::Round($p.WorkingSet64 / 1MB)
        try { Stop-Process -Id $p.Id -Force -ErrorAction Stop; $freed += $mb } catch { }
    }
}
"已释放约 $freed MB"
```

各目标说明：

| 进程 | 说明 |
|---|---|
| `cc-switch` + `msedgewebview2` | 配置切换工具的界面与其 WebView 树（约 550 MB） |
| `kernelUpdate`、`YunDetectService` | 百度网盘的版本检查/检测残留（在请求 pan.baidu.com 版本接口）；再次运行百度网盘会复活 |
| `OfficeClickToRun`、`AsusUpdateCheck` | Office 与华硕更新器，**提权进程，普通权限杀不掉**，交给 B 段 |
| `WinRAR`、`Rar`、`UnRAR` | 解压工具（本机 7.11，装在 `A:\压缩和解压软件`）。本体不常驻，**扫到即说明正在解压**，直接结束即可；右键菜单扩展 `rarext.dll` 挂在 `explorer.exe` 进程内，不是独立进程，杀不掉也不用杀 |
| `SearchHost`、`Widgets`、`WidgetService`、`TextInputHost`、`StartMenuExperienceHost`、`ShellHost`、`TabTip` | Win11 外壳与小组件（注意：会自启，见第 9 节） |
| `CrossDeviceResume`、`AppActions`、`DataExchangeHost`、`UserOOBEBroker` | 跨设备/AI 后台（约 148 MB） |
| `LockApp`、`PrintDialog`、`SystemSettings`、`ApplicationFrameHost` | 锁屏、打印、设置等 UI 残留 |
| `RuntimeBroker`、`dllhost`、`smartscreen` | 按需重启的宿主进程 |

### B. 需要提权：后台服务

服务是 SYSTEM 权限，必须先提权。若 AI 本身就是以管理员启动的（先跑第 4 节第 1 项确认 `IsAdmin: True`），**下面这套直接 `Stop-Service` 即可，输出就在当前进程里**；只有非提权时才需要把脚本写入临时文件再用 `RunAs` 启动——提权进程的标准输出不会回到调用方，所以让脚本自己写日志再回读：

```powershell
$script = @'
$log = "$env:TEMP\stop_bg_services.log"
$services = @(
    'Apple Mobile Device Service',   # Apple 移动设备支持
    'MySQL94',                       # MySQL 数据库
    'SQLWriter',                     # SQL Server VSS 写入器
    'VMAuthdService',                # VMware Workstation 授权
    'VMUSBArbService',               # VMware USB 仲裁
    'VMnetDHCP',                     # VMware NAT 网络的 DHCP
    'VMware NAT Service',            # VMware NAT
    'WSLService',                    # WSL
    'vmms',                          # Hyper-V 虚拟机管理
    'vmcompute',                     # Hyper-V 主机计算服务
    'GameViewerService',             # 网易 UU 远程
    'clash_verge_service',           # Clash Verge 代理助手
    'ClickToRunSvc',                 # Office 更新服务
    'NvContainerLocalSystem',        # NVIDIA App 后台（不影响显示与 CUDA）
    'WSearch',                       # Windows 搜索索引（减少训练期磁盘 IO）
    'DiagTrack'                      # Windows 遥测
)
$lines = @()
foreach ($s in $services) {
    try { Stop-Service -Name $s -Force -ErrorAction Stop; $lines += "已停止服务: $s" }
    catch { $lines += "停止失败 $s -> $($_.Exception.Message)" }
}
foreach ($p in @('OfficeClickToRun', 'AsusUpdateCheck', 'kernelUpdate', 'YunDetectService')) {
    try { Stop-Process -Name $p -Force -ErrorAction Stop; $lines += "已结束进程: $p" }
    catch { $lines += "进程已不存在或无法结束: $p" }
}
$lines += (Get-Service -Name $services -ErrorAction SilentlyContinue |
    Select-Object Name, Status, StartType | Sort-Object Name | Format-Table -AutoSize | Out-String)
$lines | Out-File -FilePath $log -Encoding utf8
'@
$path = "$env:TEMP\stop_bg_services.ps1"
$script | Out-File -FilePath $path -Encoding utf8
Remove-Item "$env:TEMP\stop_bg_services.log" -ErrorAction SilentlyContinue
Start-Process pwsh -Verb RunAs -ArgumentList '-NoProfile','-ExecutionPolicy','Bypass','-File',$path   # 弹 UAC，需用户点“是”
$deadline = (Get-Date).AddSeconds(100)
while (-not (Test-Path "$env:TEMP\stop_bg_services.log") -and (Get-Date) -lt $deadline) { Start-Sleep -Milliseconds 2000 }
if (Test-Path "$env:TEMP\stop_bg_services.log") { Get-Content "$env:TEMP\stop_bg_services.log" -Encoding utf8 } else { "等待超时：UAC 未确认" }
```

### C. 易漏项

- **VMware 的 `VMnetDHCP`、`VMware NAT Service` 注册在 `C:\WINDOWS\SysWOW64\` 下**，用"路径不含 C:\Windows"筛服务会漏掉它们，必须按名字显式列出（已并入上面 B 段）。
- **`HRWSCCtrl` 是火绒的服务名，进程名是 `wsctrlsvc.exe`**，用服务名去 `Get-Process` 会查不到，别误以为它没运行。
- **按名字筛压缩软件会漏**：`Get-Process -Name 'rar*'` 匹配不到 `WinRAR.exe`（名字以 `Win` 开头），要写 `'WinRAR'` 或 `'*rar*'`；本机压缩软件还装在 `A:\压缩和解压软件` 而不是 `C:\`，按盘符筛同样会漏（同 VMware 那个坑）。
- 已经 `Stopped` 但 `StartType=Auto` 的第三方服务（`AweSunService`、`ToDesk_Service`、`BaiduNetdiskUtility`、`EpicGamesUpdater`、`GoogleUpdater*`、`edgeupdate*`、`Steam Client Service`、`Pluto Service`、`com.docker.service`、`Bonjour Service` 等）本身不占资源，**不要去改启动类型**；它们可能在训练中被定时任务唤醒（对应处理见 D/E/F 段，属持久性改动，需用户同意）。

### D. 提权：暂停 Windows 更新（防训练中途重启）

本机活动时间为 8:00–2:00，即**凌晨 2:00–8:00 在活动时间之外，Windows 可自动安装更新并重启**；跨夜的长训练必然覆盖该时段。开训前暂停更新 5 周（提权执行）：

```powershell
$start = (Get-Date).ToUniversalTime().ToString('yyyy-MM-ddTHH:mm:ssZ')
$end = (Get-Date).ToUniversalTime().AddDays(35).ToString('yyyy-MM-ddTHH:mm:ssZ')
$ux = 'HKLM:\SOFTWARE\Microsoft\WindowsUpdate\UX\Settings'
foreach ($n in 'PauseUpdatesStartTime','PauseFeatureUpdatesStartTime','PauseQualityUpdatesStartTime') { Set-ItemProperty -Path $ux -Name $n -Value $start -Type String -Force }
foreach ($n in 'PauseUpdatesExpiryTime','PauseFeatureUpdatesEndTime','PauseQualityUpdatesEndTime') { Set-ItemProperty -Path $ux -Name $n -Value $end -Type String -Force }
```

复核：`(Get-ItemProperty 'HKLM:\SOFTWARE\Microsoft\WindowsUpdate\UX\Settings').PauseUpdatesExpiryTime` 应为 5 周后的 UTC 时间，设置界面会显示"更新已暂停至 …"。暂停不等于关闭更新，到期自动恢复。

### E. 提权：禁用重型自启项

这些条目现在未必在运行，但**重启后会全部回来**，是长训练最大的隐性开销：

| 自启位置 | 条目 | 开机后会发生什么 |
|---|---|---|
| HKCU `...\CurrentVersion\Run` | `WallpaperEngine` | 动态壁纸，持续占 GPU 渲染 |
| 同上 | `GameViewer`（网易UU远程，`--auto-run`） | 远程控制服务，截屏编码，GPU/CPU 双占 |
| 同上 | `Docker Desktop` | 虚拟化 + 常驻后台 |
| 同上 | `Steam`（`-silent`） | 常驻 |
| 启动文件夹 | `Ollama.lnk` | 本地大模型服务，**会占显存** |

做法：**先整键导出备份**再删除；启动文件夹里的快捷方式只移动、不删除。

```powershell
reg export "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" "$env:USERPROFILE\autostart-backup\HKCU-Run-backup.reg" /y
foreach ($n in 'WallpaperEngine','Steam','GameViewer','Docker Desktop') { Remove-ItemProperty -Path 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' -Name $n -Force -ErrorAction SilentlyContinue }
Move-Item "$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup\Ollama.lnk" "$env:USERPROFILE\autostart-backup\Startup\" -Force -ErrorAction SilentlyContinue
```

- **`GameViewer` 会自愈自启项，只删 Run 键治标不治本**：2026-09-16 重启后复查，被移除的 `GameViewer` 又出现在 Run 键里（值 `"A:\远程控制软件\网易UU远程\GameViewer\GameViewer.exe" --auto-run`）。原因是 `GameViewerService` 的 `StartType=Automatic`，开机自启后由它把该键写回。要根治得**把 `GameViewerService` 启动类型改成 `Disabled`**（持久性改动，需用户同意），或在 UU 远程软件内关闭"开机自启"。其余三条（`WallpaperEngine`、`Steam`、`Docker Desktop`）重启后没有再回来。

未处理的轻量项：`AMDNoiseSuppression`、`electron.app.WeChatDataAnalysis`、`iTunesHelper`、`Everything`、`vmware-tray`（注册表里有重复两条）、启动文件夹的 `Clash Verge.lnk`——不影响训练，默认保留。

### F. 提权：禁用第三方计划任务

Google / Firefox / Git / NVIDIA / Edge 的更新器，以及 `SoftLanding`、`WiseCleaner` 这类推广任务，会在训练中途唤醒，造成 CPU 与磁盘抖动：

```powershell
$records = @()
foreach ($t in (Get-ScheduledTask | Where-Object { $_.State -ne 'Disabled' -and $_.TaskPath -notmatch '^\\Microsoft\\' -and $_.TaskName -notmatch 'Huorong' })) {
    Disable-ScheduledTask -TaskPath $t.TaskPath -TaskName $t.TaskName | Out-Null
    $records += "$($t.TaskPath)`t$($t.TaskName)"
}
$records | Out-File "$env:USERPROFILE\autostart-backup\disabled_tasks.txt" -Encoding utf8
```

- **必须排除 `\Huorong PopBlock`**：它是火绒的弹窗拦截任务，禁掉就违反了"火绒不动"的要求（2026-09-15 误禁过一次，已恢复）。
- 记录文件按「任务路径 + Tab + 任务名」两列写入，恢复脚本据此逐条启用。

D/E/F 三段做完后，跑第 5 节验证，并把备份目录 `%USERPROFILE%\autostart-backup\` 的路径告诉用户。

## 4. 执行前的安全检查

```powershell
# 1) 是否已提权（False 表示需要走 B 段的 RunAs）
([Security.Principal.WindowsPrincipal][Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)

# 2) 系统代理：停 clash_verge_service 前确认没有在用代理，否则可能自断网络（AI 自己的连接也会断）
Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings' | Select-Object ProxyEnable, ProxyServer
Get-NetAdapter | Where-Object { $_.InterfaceDescription -match 'TAP|TUN|WireGuard|Wintun|VPN' }   # 有 TUN 网卡说明流量走代理，先停手
@(Get-Process | Where-Object { $_.ProcessName -match 'clash|mihomo|xray|v2ray|sing-box' }).Count      # 只有 *-service 助手、没有代理核心 = 安全

# 3) 是否有虚拟机在跑：有则不要停 vmms / vmcompute / VMware 服务
@(Get-Process | Where-Object { $_.ProcessName -match 'vmmem|vmware-vmx|vmwp' }).Count

# 4) 训练进程是否已在运行
@(Get-Process | Where-Object { $_.ProcessName -match 'python|yolo|tensorboard' }).Count
```

2026-09-15 实测：`ProxyEnable=0`、无 TUN 网卡、无代理核心、无运行中的虚拟机、python 进程 0 个，四项均通过。

## 6. 恢复

- **首选：重启电脑**。所有服务的 `StartType`（Automatic / Manual）一个字没改，重启后原样恢复。
- 不想重启：管理员 PowerShell 里 `Start-Service <服务名>` 单独拉起，例如要用 VPN 时 `Start-Service clash_verge_service`。
- 被结束的进程（cc-switch、百度网盘助手、Office/华硕更新器）随对应软件下次启动自动回来。
- **自启项、计划任务、更新暂停**：以管理员运行 `%USERPROFILE%\autostart-backup\restore-autostart-and-update.ps1`，它会导入 `HKCU-Run-backup.reg`、把 `Startup\*.lnk` 移回启动文件夹、按 `disabled_tasks.txt` 逐条启用任务、清除 6 个更新时间值。

## 9. 杀了也白杀 / 不值得杀

- **Windows 外壳进程会自启**：`StartMenuExperienceHost`、`SearchHost`、`TextInputHost`、`ShellExperienceHost`、`ShellHost` 和它们的 `msedgewebview2` 子进程，被杀后几秒内自动重建。杀掉只能短暂释放，用户一碰开始菜单或一打字就回来，**不必反复追杀**。
- **火绒**（`HipsDaemon` 等）保留，且 194 MB 不构成负担；要减少它对训练的干扰应该加**目录白名单**而不是关防护（见第 10 节）。
- **`SystemSettings`、`ApplicationFrameHost` 等 UWP 宿主**杀掉后会随用户操作重建，收益是临时的。

## 10. 真正影响训练速度的三件事

清理进程/服务只能拿回约 0.6 GB，下面三条的收益更大：

1. **PyCharm 开 Power Save Mode**（File 菜单）：它占 3.45 GB，索引器和 AI 补全（`full-line-inference`）会在训练时与 DataLoader 抢 CPU 和磁盘；或训练期间直接关掉 IDE。
2. **给火绒加目录白名单**：把 `datasets/`、`数据集/`、`runs/` 加入信任区。首个 epoch 要生成几千个 npy 缓存文件，实时扫描是纯开销。
3. **训练期间关掉 AI 会话**（`claude.exe` 约 420 MB）和不再需要的浏览器/工具窗口。

此外提醒：可用内存虽然涨到 19.2 GB，但五通道全量 RAM 缓存需要约 18 GiB，**`main.py` 的 `cache` 仍应保持 `disk`**，不要因为"内存变多了"改成 `ram`（会紧贴上限触发换页，反而更慢）。

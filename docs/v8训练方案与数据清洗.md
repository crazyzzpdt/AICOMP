## 三、v8 配方

从 `orgin_models/dfine_l_obj365_e25.pth` 官方预训练重新迁移，`resume=None`，不是续训已过拟合的 v7；仍使用 D-FINE-L 五通道，不盲目更换更大的架构。

| 项目 | v8 设置 |
|---|---|
| 分辨率 / 物理批次 / 有效批次 | 1280 / 4 / 16；物理批次按 v6 实际 args.yaml 恢复 |
| 轮数 / 预热 | 最多 60 轮 / 3 轮，保留 v6 余弦周期 |
| 主学习率 / 骨干学习率 | 5e-5 / 5e-6，相对 v6 减半 |
| 优化器 / 权重衰减 | AdamW / 1e-4；偏置和一维参数不衰减 |
| 学习率计数 | 按真实 optimizer step，累积尾组按实际样本数归一化 |
| 增强 | 尺度 0.9–1.0、同步水平翻转、温和 RGB HSV |
| 关闭项 | v7 完整目标裁剪、低清模拟、boat/garbage can 重复采样 |
| 收尾 | 第 41 轮关闭尺度扰动，若此前早停则不会补跑 |
| 原生损失 | VFL=1、BBox=5、GIoU=2、FGL=0.15、DDF=1.5 |
| 早停 | mAP50-95 连续 10 轮没有累计超过 0.0005 的有效提升 |
| 权重 | 所有真实 AP 新高仍更新 best；另存 best_map50、last、每 5 轮检查点 |

降低学习率、回撤增强是针对过拟合和域差异的候选调整，不代表已找到最优值。早停只减少无效后续训练，不能让已有最佳权重凭空涨分，也可能错过晚期改善。没有自动探测显存或替用户释放资源。

正式训练每轮复用同一批验证预测，额外写 `domain_metrics.csv` 的 PNG/JPG 总体和逐类 AP，不增加模型前向；缺少该类 GT 的域指标留空。JPG 少数类别、少场景指标不可与 PNG 平均后当成官方分数。采样关闭，不生成新的 `sampling_history.csv`。

启动时核验当前图像清单和全部标签指纹；恢复额外要求审计指纹、数据签名和训练适配源码指纹一致。早停完成的 last.pth 不能当作中断恢复。运行目录保存 `dataset_audit.json` 和代码快照，避免训练之后失去数据依据。

## 四、启动及结果解释

直接执行：

```powershell
uv run python main.py
```

结果进入 `runs/detect/AIC_RGBIRDepth_dfine_l_1280_v8`，重名自动另建带时间戳目录。**验证集已改变，v8 本地 AP 不能与 v4/v6/v7 的 AP 直接横向排名**。应先看新验证集内的趋势、各类与各域表现，最终提高与否仍以同规则线上提交为准；本次未额外复评旧模型。

训练完成后使用实际新目录进行预测：

```powershell
uv run python predict.py --weights runs/detect/AIC_RGBIRDepth_dfine_l_1280_v8/weights/best.pth --imgsz 1280 --batch 18 --output predict_v8
```

保留用户 `predict.py` 的现有 v7 默认权重和资源设置，故不能不传参数就认为预测的是 v8。D-FINE 新权重为 `.pth`，不是 YOLO 的 `.pt`。预测保持 FP32、conf=0.001、max_det=100，不引入未证实有效的 NMS/TTA/WBF；旧五通道 YOLO `.pt` 仍走兼容后端，RGB 三通道官方基底不能直接替代已训练的五通道检查点。

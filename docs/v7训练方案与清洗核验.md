## 两类受限重采样与 D-FINE 对应配置

每轮1744张原图全部覆盖一次。只对含boat或garbage can的训练图按概率补充一次，同图含两类取较大倍率，不将倍率相乘。单图每轮最多2次，每轮额外样本最多174张，每个文件名近似场景组最多额外4张；组由文件名前缀和纯数字ID间隔大于50的连续段构成，仅作重复限制，不声称语义场景识别正确。受上限影响，实际倍率可能低于1.5/1.25，以运行记录为准。

抽样使用seed+epoch的局部随机状态，完整图像与所有类别标签一起采样，不把其他类别从图中删除；验证集保持原样。第31轮起停止额外重复。`sampling_history.csv` 在各轮开始记录原图数、总抽样数、额外数量、含船/含垃圾桶的图像抽取次数和计划优化步数；若该轮中断，不能把这行记录视为已完成训练。`optimization_recipe.json` 同时保存各轮长度和原生损失权重。

梯度累积尾组按当轮实际采样数量计算，不能仍用1744计算，否则额外样本可能遇到错误的损失归一化。新日程按全部轮次计划的优化步计数，累积组内学习率固定，收尾关闭重复不会导致进度倒退。恢复通过seed+epoch重建同轮清单，且校验全部新增配方字段；旧配方缺省关闭重复并保留旧日程，不静默改变其行为。

| v4 YOLO 设置/目的 | 当前 D-FINE 处理 |
|---|---|
| 清洗标签 | 已沿用且指纹核实，不重复清洗 |
| AdamW、lr0=1e-4、nbs=16、cos_lr | 主学习率1e-4、骨干1e-5、有效批次16、优化步余弦 |
| weight_decay=0.0005 | 不等比搬运，采用官方微调值0.000125；偏置/一维参数不衰减 |
| cls_pw=0.25 | 无直接等价参数；以两类限额采样调整训练出现频率，不额外分类加权 |
| box/cls/dfl | 显式使用 loss_bbox=5、loss_giou=2、loss_vfl=1、loss_fgl=0.15、loss_ddf=1.5，均为已固定官方配置的默认值 |
| Mosaic、scale、translate、close_mosaic | 不复制YOLO拼图配方，以同步尺度/完整目标裁剪及第31轮收尾实现相关泛化意图；并非数学等价 |

上述损失权重实际传入官方criterion，而非只写注释。loss_ddf是同一D-FINE模型内部定位自蒸馏，不是新增教师网络，也不是比赛禁止的多模型平均。没有证据支持把框损失盲目加倍，或认为这些官方默认值已经针对本比赛最优。

## 为什么没有把所有方法一起打开

- 不搬回 v5 全套强重采样、目标裁剪及模态缺失：v5改善ball但线上明显退步，不能认为全部技巧都有益。本次只加两类轻量重复；v5原采样类包含garbage can但不包含boat，垃圾桶问题不能仅归因于训练次数不足。
- 不增加外部数据、不以测试集补标或训练；不做多模型集成。
- 不默认TTA/WBF：合规边界及收益没有确认，不以“全用上”代替判断。
- 不自动重新分配数据：现有验证缺少JPG场景、稀有类仅少量框的问题仍存在；必须先人工确认真实场景组，防止相邻帧泄漏。仅按文件名重新洗牌不是可靠修复。
- 不从预测结果自动补标签、删除难例。后续人工复核优先 garbage can、boat、ball、sign、light，保留证据和回滚记录。

用户禁止额外测试，本次不做统一复评、难例推理或新训练，因此上述未验证项明确保留，不冒称已解决。原1744/256划分与清洗副本完整保留，v4仍为线上正式基线。

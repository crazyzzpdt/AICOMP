# v11复盘与v12训练方案

更新：2026-09-20。只读取已有训练产物和历史代码，没有运行额外评估、测试、训练或推理。

## v11结论

v11正常通过第10轮门槛，并在第20轮因历史最佳AP95=0.32668低于0.34停止。最佳出现在第5轮：mAP50=0.52537、mAP50-95=0.32668。停止是预设筛选生效，不是异常崩溃；用户后续提交得到线上44.4710。

关闭`cls_pw`解决了一部分ball问题：第5轮ball AP50=0.52781、AP95=0.41520，明显高于v10最佳总体轮的ball AP95=0.03541。但v11总体没有提高，且后续ball仍回落；这说明类别频率权重会影响弱类稳定性，却不是当前总体分数的主要瓶颈。

v4仍是唯一线上达到55.6000的方案，使用原生1280方形几何。v9至v11改为1920×1088固定矩形后，线上和本地总体指标均没有超过v4。更大输入保留了像素，但同时改变了填充、Mosaic、透视增强、批次内几何和目标尺度分布；“像素更多”不等于有效监督更多。

## v12方案

v12恢复v4的原生1280数据链，而不是从v4权重续训：

- 官方YOLO26l重新迁移，五通道首层早期融合；
- 当前清洗版1709 train / 291 val与审计保持不变；
- 原生1280×1280 LetterBox、Mosaic和检测增强链；
- batch4/nbs16、AdamW 1e-4、warmup 5、200轮余弦；
- 前100轮Mosaic0.5、scale0.3、translate0.1，后100轮关闭Mosaic；
- HSV全部为0、`cls_pw=0`，保留ball语义迁移；
- 固定双头0.8/0.2、FP32单标签验证、best按AP95保存；
- 第10轮历史最佳AP95须达到0.34，第20轮须达到0.36，否则停止。

本轮不同时加入ball/tricycle采样。v11已经证明ball能够学到，当前首先隔离固定矩形几何是否是总体回退来源；若v12通过门槛但最终只在极少类上回退，再单独加入限额采样才有可解释性。

v4的验证集为旧256张，v12为当前291张，不能要求本地AP逐点复现；真正是否超过v4仍以赛事提交为准，也不承诺达到60分。

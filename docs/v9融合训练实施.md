## 2. 真正落实 1920×1080，而不是只把 imgsz 改成 1920

- 外部五通道顺序仍为 RGB3、IR1、Depth1，模型内部拆成三个分支。
- 内容窗口是宽 1920、高 1080。1080 不是网络最大步长 32 的整数倍，因此画布仅补边到宽 1920、高 1088，标准 1080p 图像上下各补 4 像素，不先缩成 1280，也不拉伸到 1088。
- 原生 YOLO 训练参数 `imgsz` 使用标量长边1920，由 `RectangularDataset` 输出固定矩形；`rect=False` 不代表本实现输入为正方形。最初`IMAGE_HW=(1080,1920)`按高、宽书写；当前工作区改成宽、高后，须同时调整所有索引，见上方开训阻塞说明。
- 不同原尺寸图像等比放入内容窗口，不强行改变目标长宽比。低清 JPG 放大不会产生新的真实细节，较大输入也不保证提高泛化成绩。
- 前 80 轮允许温和同步几何增强和概率 0.25 的矩形四图拼接；不是每次都保持原像素一比一。第 81 轮起关闭拼图、尺度及位移，回到完整画面收尾。
- 验证与预测使用同一 `letterbox_fused`，不做随机增强。三模态共用缩放和填充；HSV 仅用于训练 RGB。OpenCV 缩放/仿射逐通道执行，避开此前五通道插值报错。

## 3. 结构与权重迁移

`aic/model.py` 的 `FusionDetectionModel` 保留官方 YOLO26l 三通道 RGB 主干，红外、深度分别经轻量卷积和 GroupNorm 提取三尺度特征，在 P3/P4/P5 经投影和可学习空间门控加入 RGB 特征，送入同一颈部和检测器。

辅助投影以小幅非零参数初始化，门控偏置为 -2；这是保护初始 RGB 表示的设计，不是把模态固定清零。真实贡献由训练学习，不保证能修正严重配准偏差。正式训练记录分支梯度和门控概况，用于发现失活，不等于证明提分。

初始化为本地官方 `orgin_models/yolo26l.pt`，不是旧 v4/v5 或 D-FINE 项目权重。分类层按匹配语义迁移，并显式检查两个训练分支的 `sports ball→ball=7` 权重与偏置；不把一个 COCO 动物类冒充全部 animal。

训练保留原生一对多和一对一分配，损失全程固定为 0.8/0.2。正式验证、提交只使用一对多输出，不融合两个头。这样不再借 5000 个总 epochs 间接控制损失比例；这仍是候选设计，尚无本轮效果证据。

## 4. 已写入的参数

| 项目 | 本轮设置 |
|---|---|
| 内容 / 网络张量 | 1920×1080 / 5×1088×1920 |
| 训练 / 验证 / 预测 batch | 2 / 1 / 4；峰值显存未实测，由用户调整 |

| 训练精度 | BF16；验证及预测 FP32 |
| 加载 | workers=4、预取 1 批、pin_memory=False、cache=False |
| 周期 | 最多 120 轮，预热 5 轮，余弦衰减到各组初始学习率的 1% |
| AdamW 学习率 | RGB 主干 2e-5、颈部/检测头 1e-4、IR/Depth/门控 2e-4 |
| 衰减 | 5e-4，偏置和归一化参数不衰减，实际参数组写入配方 JSON |
| 几何增强 | mosaic=0.25、scale=0.2、translate=0.05、fliplr=0.5 |
| RGB 增强 | HSV=0.01/0.15/0.15 |
| 收尾 | 第 81 轮起关闭 Mosaic/scale/translate；保留翻转与 RGB 增强 |
| 早停 | 收尾阶段重新计数，至少允许 20 轮收尾；patience=20、min_delta=0.0002 |
| 类别策略 | cls_pw=0、不重采样、不裁弱类、不随机丢模态 |
| 检测候选 | 单标签 NMS，conf=0.001、iou=0.7、max_det=100 |
| 权重留存 | best.pt 按 AP95；best_map50.pt 单独留存；last.pt；原生每 20 轮周期文件 |

默认训练 batch=2 是未经试跑的起点，不代表恰好用满 15GB。若用户改为 4，稳态累积自动改为 4 批。保持 nbs=16；不要为了凑满显存而盲目增加有效批次。原生训练期间若遇 OOM 可能按框架逻辑减小 batch，这不是本轮执行了自动探测。

## 5. 验证、提交与记录

- 两端共享五通道读图、等比矩形填充、除以 255、单标签 NMS和内容区裁框；补边中的退化框不会只在提交时消失。验证在画布坐标匹配，提交逆变换回原图，两者保持同一几何口径。
- FP32 指前向和后处理精度；YOLO 原生 `.pt` 序列化 EMA 为半精度、加载时转回 FP32，不能宣称与保存前的 FP32 EMA 逐位相同。
- 一份检查点、一次常规前向、一个尺度；没有多权重 WBF、投票、TTA 或弱类重检测。`visual_conf=0.25` 仅决定画框展示。
- 每轮正常验证记录 `results.csv`、12 类 `per_class_metrics.csv`、复用同批预测的 `domain_metrics.csv`。分域 AP 不额外运行模型。
- `fusion_diagnostics.csv` 记录两头平均损失、六个门控均值及辅助编码器末次优化步梯度范数。它们不是完整分布统计，也不构成模态收益消融实验。
- `optimization_recipe.json` 留存矩形尺寸、双头比例、参数组、源码/框架/清洗审计指纹；同时保存入口及组件源码快照、数据审计快照。
- 原生曲线和混淆矩阵在收尾或末轮生成；取消训练结束后再次加载最佳模型的独立复评。图上的末轮指标不应冒充 `best.pt` 所在轮指标。
- 预测元数据记录结构版本、内容尺寸、张量尺寸、检查点轮数及权重指纹。融合模型不走历史 `yolo_profile=v4/current` 路径。

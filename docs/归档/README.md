## 归档规则

- 保留原始记录、日期、来源文件名及已有`record-*`锚点，不通过改写历史结论制造一致性。
- “当前”“下一轮”“尚未训练”“已授权”等表述只属于原记录时点，不构成现在的配置或执行授权。实际结果以日期更晚且有运行产物依据的记录为准。
- 旧`main.py`/`predict.py`命令、历史权重、旧数据划分或历史清洗流程不得直接用于当前运行。若需要复现实验，应先核对对应源码快照、数据与许可约束。
- 训练峰值、独立重载复评、初赛与复赛成绩分开记录；跨划分的AP不能直接排名，不按类别拼接不同轮次峰值。
- 归档只整理Markdown及引用，不移动`runs/`、数据集、权重、预测产物或官方资料原件。未另行授权时不启动模型任务、不提交或推送Git。
